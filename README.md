# HOS Consult Limited — V2 local copy

This folder is a local copy of the HOS Consult V2 AppDeploy source snapshot. The existing `hosconsultwebsite` folder is untouched; do not remove it until you have confirmed this copy runs correctly.

## Run locally

1. Install Node.js if it is not already installed.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.

This folder is a source snapshot; local edits do not automatically update the AppDeploy site.
